# Código de conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/)
([English](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)).

En resumen: tratá a las demás personas con respeto, aceptá críticas constructivas y enfocate en lo que es mejor
para la comunidad. No se toleran el acoso, los ataques personales ni la publicación de información privada de
terceros.

## Reportes

Si presenciás o sufrís una conducta inaceptable, reportala de forma privada a quienes mantienen el proyecto
mediante el formulario de la pestaña **Security → Report a vulnerability** de este repositorio, indicando que se
trata de un reporte de conducta. Todos los reportes se revisan con reserva.
