# Security policy

## Reporting a vulnerability

Please report vulnerabilities **privately**, through
[Security → Report a vulnerability](https://github.com/sifen-sdk/sifen-sdk-java/security/advisories/new)
on this repository. Do not open a public issue.

You can write in Spanish or English. Include the affected version or commit, what an attacker could do, and steps
to reproduce. You should get a first answer within 7 days.

## Never share real material

Do not include real certificates, private keys, passwords, security codes (CSC) or production documents in a
report, an issue or a pull request. If you published one by accident, revoke it with your certificate provider:
deleting the message is not enough.

## Supported versions

No version has been released yet. Once releases exist, the supported lines are listed in
[docs/versiones-y-soporte.md](docs/versiones-y-soporte.md).

## Scope

This SDK handles signing keys and fiscal documents. Reports about key handling, signature creation or
verification, XML parsing, TLS configuration, and leakage of secrets or personal data in logs or error messages
are especially welcome.
